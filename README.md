
# OCR Matrículas España

Aplícación complementaria a "Detector de Matrículas". Permite importar CSV para usar como registros a comprobar durante el reconocimiento/lectura.

Permite lectura modo manual y modo vídeo con varios niveles de zoom y linterna.

Puedes agregar mensajes personalizados para determinadas mastrículas, así como establecer la duración de los mensajes al ser detectadas.

El historial se puede exportar para su analisis junto a los datos de "Detector de Matrículas" y así ver las zonas donde un vehículo de determinada matrícula estaciona mal y bien.
